
# Python Expense Tracker

A command-line expense tracker built with Python.

## Features

- Add expenses with a description, category, amount, and date
- View expense history
- Calculate total expenses
- Calculate totals by category
- Save expense data locally in a JSON file
- Validate amounts and handle invalid input

## Requirements

- Python 3
- No external packages required

## How to Run

```bash
python expense_tracker.py
```

## Run Tests

```bash
python -m unittest -v
```

- Python
- JSON
